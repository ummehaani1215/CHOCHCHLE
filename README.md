#  Wedding Anniversary Surprise

A small, personal anniversary website created as a surprise for a beautiful couple celebrating their 1st wedding anniversary. 💍✨

## About the Project

This website is a simple interactive surprise page.

The flow is:

1. The couple opens the website.
2. They enter their names.
3. The names are checked.
4. If the correct names are entered, the anniversary page opens.
5. The page displays a special anniversary message and a personal photo. ❤️
